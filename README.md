# 夜の自販機（yorujihanki）

真夜中に立つ自販機。ボタンを押すと出てくるのは飲み物ではなく、「今夜の気分」が入った缶です。

## あそびかた

- 4つの味ボタン（あまい／にがい／からい／しずか）から1つ押すと、その味の「気分の缶」がランダムで取り出し口に落ちてきます。
- たまに（約12%）缶がつかえてしまいます。そのときは「ゆする」ボタンで自販機をゆすってください。ゆすると、メニューにはないレアな缶が出てきます。
- 気に入った缶は「ポケットに入れる」でコレクションできます。ポケットの中身はブラウザの localStorage にのみ保存され、サーバーには送信されません。ポケットの缶は1つずつ取り出す（削除する）こともできます。

## 技術

- Python / Flask の単一ファイルアプリ（`app.py`）。サーバー側に状態は持たず、抽選・演出・ポケットの保存はすべてブラウザ側の JavaScript で行います。
- 自販機と缶は CSS のみで描画しています（画像ファイル不使用）。
